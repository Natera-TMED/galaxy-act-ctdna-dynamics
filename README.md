# galaxy-act-ctdna-dynamics

Analysis code for "Serial circulating tumor DNA monitoring to inform adjuvant chemotherapy
utilization and duration in resected colorectal cancer: results from the GALAXY observational study".

## Contents
- `cohort1/`: Cohort 1 figures and supplementary tables (Python)
- `cohort2/`: Cohort 2 landmark Kaplan-Meier and adjusted Cox analyses (R Markdown)
- `cohort3/`: Cohort 3 analysis and tables (Python)
- `table1_overall_characteristics.py`: Table 1 summary
- `_common.py`, `_helpers.py`: shared functions used by the Python scripts
- `report/`: rendered HTML reports

## Data
Patient-level data are not included. Data sharing is described in the manuscript.
